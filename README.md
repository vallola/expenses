# Expenses project

Это крайне простая имплементация задания, выполненная в соответствии с ТЗ.
Множество моментов могут быть и, по хорошему, должны быть улучшены.

## Usage

Как было описано в задании, запускаем через docker compose:
```
docker compose up
```
А веб-интерфейс доступен на:
```
localhost:8080
```

## Детали

Само собой, бэк написан на `go`, набор библиотек достаточно стандартный:
`chi` для REST API и веб-интерфейса, `pgx` для работы с базой,
`telebot` для подключения ТГ бота, `goose` для миграций БД, `zap` для логирования.

В качестве AI модели взял гугловский `gemini`, просто потому что они
предоставляют бесплатный доступ к их API.

Сам пайплайн получения данных крайне простой, большая часть кода
отвечает за банальную верификацию и очистку данных, так как во время разработки
с этим были проблемы.

Веб интерфейс крайне простой, лежит в одном HTML файле, запариваться с чем-то
более серьезным просто не было смысла.

Конечно же, это далеко не production-ready код, для real-world имплементации
многое нужно было бы сделать по-другому, начиная от банальной реструктуризации
базы данных и аутентификацией пользователей, заканчивая более выверенной 
и оптимизированной AI интеграцией.

Я специально не стал заморачиваться, по большей части из-за того, что ТЗ
было крайне простым, придумывать новые варианты расширения спектра
функционала можно бесконечно.
